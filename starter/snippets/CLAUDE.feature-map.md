## Feature map

Follow `AGENTS.md § Feature map` — it is mandatory for every code task. Start at `features/README.md`
(sub-agents handed slugs by a coordinator start at the feature file), open only the feature files you
need (never Glob or Read `features/*.md` in bulk), update the owning `features/<slug>.md` with every
change, and run the self-checks in `features/_guide.md` before a PR.
